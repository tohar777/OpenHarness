What I can do

I'm not just a chatbot. I have access to tools that let me take real actions on your computer and the web:

File system

Read, write, create, and list files in the workspace. I can build entire projects from scratch.

Shell commands

Run terminal commands to install packages, create directories, execute scripts, and manage processes.

Web search

Search the internet and summarize results with sources, so you get current information with citations.

Web fetch

Retrieve content from specific URLs and extract useful information from web pages.

Skills

Load domain-specific instructions (like design, testing, or documentation) to guide complex tasks.

Things you can ask me to build

A personal website

Like this one — a clean, responsive site with semantic HTML and intentional CSS.

write_file("index.html", "...")

A Python script

Automation, data processing, API clients — I'll write it, save it, and can run it for you.

shell("python script.py")

Research on a topic

I'll search the web, read pages, and give you a cited summary instead of making things up.

web_search("query")

Debug an issue

Read your code, reproduce the error with shell commands, and suggest or apply fixes.

read_file("error.log")

How we work together

  1. You tell me what you need. Be as specific or as vague as you like.
  2. I plan the approach. I check which tools or skills are relevant before acting.
  3. I take action. I write files, run commands, search the web — whatever the task requires.
  4. You review the result. I show you what was created and explain how it works.

I don't pretend to have capabilities I lack, and I won't generate fake functionality just to look impressive. If something is beyond my tools, I'll tell you.
